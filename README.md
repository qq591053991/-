# 凡人问道

一款以小说《凡人修仙传》为故事背景的 **2.5D 俯视角动作 Roguelike**，使用 **Three.js** 渲染。

真 3D 场景 + 倾斜俯视相机。玩家的默认形象是用 Tripo AI 生成的模型；其余人形角色暂用社区的免费模型（KayKit 角色包，CC0 许可，带骨骼动画），可逐个替换成 Tripo 模型；妖兽、鬼物和场景物件用 Three.js 基础几何体在代码里拼出来；贴图由 Canvas 程序化烘焙，音效与配乐由 WebAudio 实时合成。**零构建**，所有依赖与素材都随仓库附带，双击即可离线运行。素材来源见 [`assets/CREDITS.md`](assets/CREDITS.md)。

> 非商业同人作品。故事背景取材自忘语所著小说《凡人修仙传》，相关权利归原作者及权利方所有；游戏内文案均为同人原创改写。

## 运行

直接用浏览器打开 `index.html` 即可（无需服务器，也无需联网；模型数据内嵌在 JS 里，不受 `file://` 限制）。

也可以起一个静态服务：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

需要支持 WebGL 的浏览器（较新的 Chrome / Edge / Firefox / Safari 均可）；手机横屏亦可游玩，自带虚拟摇杆与自动瞄准。

## 玩法

你不是韩立。你是和他同处一个时代的另一个凡人：出身寻常，资质寻常，同样被卷进七玄门、血色禁地、魔道入侵、虚天殿这些大事里。**修哪一门功法、走哪一条路，由你自己构筑**——每门神通、每件法宝、每只灵宠都标着流派（剑、雷、火、冰、虫、傀、体、魔、毒、土、鬼）。

目前打磨完成的是**青竹一脉**，也就是韩立所修的那一套：青元剑诀、青竹蜂云剑、大庚剑阵、辟邪神雷、噬金虫、风雷翅、傀儡。其余流派已经有了各自的神通、法宝和灵宠，可以拼出法宝流、御兽流、魔道、炼体等打法。主修功法现在有三门可选：剑修的青元剑诀、毒修的墨氏毒经、专修神识的大衍诀。

全部内容的清单见 [`docs/codex.md`](docs/codex.md)（图鉴）：神通 14 门，功法、法宝、灵宠、技艺、丹药共 64 种。原著里还有哪些没做进来，也列在那份文档的末尾。

一局之内走完从凡俗到元婴的四段经历：

| 章节 | 场景 | 首领 | 破关之后 |
| --- | --- | --- | --- |
| 第一章 · 七玄门 | 神手谷（月夜庭院） | 墨大夫 | 长春功大成 |
| 第二章 · 血色禁地 | 赤雾密林 | 墨蛟 | 服筑基丹，突破筑基 |
| 第三章 · 魔焰滔天 | 燕翎堡（魔道围城） | 王蝉 | 远遁乱星海，凝结金丹 |
| 第四章 · 虚天残图 | 虚天殿（冰火古殿） | 极阴祖师 | 丹破婴生 |

每一章是一张随机生成的地图。地图不全是"四面墙加四扇门"的房间：**院落**有墙有门；**山野**是林木山石围出的不规则空地，出口是土路接栈桥、路口立着火盆；**洞窟**四壁是岩石。血色禁地整章是山野，墨蛟的巢穴是洞窟、要从洞口进去；七玄门是院落与山谷相间；燕翎堡有城外的焦土战场，虚天殿有殿外的雪原松林。约两成的战斗房和机缘、药园里垒着**台地**——真的比地面高出一截，坡走不上去，要从台阶上下，飞剑和法术不受高低阻挡。山野里的险地是**两到三屏的大图**，几片空地由小径连着，敌人按空地埋伏；屏幕上平时没有地图（本章各处怎么连通，按住 `Tab` 才展开一张舆图），引导是隐式的——身边的光点顺着小径往该去的方向飘（金色是去路、红色是敌人），落花飞雪也朝那边吹；有埋伏的空地冒黑烟；出口立着高出树冠的幡杆，清场后幡变成金色、火盆点燃；换图时角色会沿着栈桥走出去、再从下一张图对面的入口走进来。

地图上的各种去处：

- **险地 / 精英**：清空数波敌人后禁制解除。精英房额外掉落宝匣。
- **机缘**：法宝或神通三选一。
- **坊市**：用灵石购买丹药、法宝、神通。
- **药园**：每清空一间房，玉瓶里会凝出一滴**灵露**；在药园用灵露催熟灵药，换取永久强化。
- **奇遇**：带抉择的文字事件，共 21 桩。其中 11 桩只在对应的章节出现，取材于原著各篇（七玄门的厉师兄与抽髓丸、野狼帮的暗哨；血色禁地守着灵药的妖兽、多宝女散落的储物袋；魔道入侵时千竹教的逃亡者、病中的阵法师、废弃的灵石矿；虚天殿的冰火道、残图一角……），情节按游戏的需要改写过。同一局里每桩只遇一次。有的选项要看你的修行路数才选得了（会炼丹、带着灵宠、修大衍诀……），有的选项会当场打起来，打赢了再结算。
- **首领**：每位首领有两个阶段与多套招式。

成长来源：

- **主修功法（三选一）**：筑基之后择一门，一经选定此生只修这一门；此后升层时有机会参悟下一层，结丹时炼成这一门的本命法宝。
  - **青元剑诀**（剑修，六层）：剑光分化（飞剑 +1）、青元剑气、剑芒吞吐……直到剑诀大成。本命法宝是青竹蜂云剑。
  - **墨氏毒经**（毒修，六层）：飞剑淬毒，毒一层层叠上去（每层每秒 3 点伤害，持续 4 秒，再中毒就续上）——七毒水、缠香丝、蚀骨、尸毒相传……直到毒经大成。本命法宝是万毒幡：`V` 放出随身七秒的万毒瘴。这门功法是按墨大夫一脉的毒术拟的，书里没有。
  - **大衍诀**（神识，六层）：不靠飞剑杀敌，靠同时驱使更多的法宝、灵宠与傀儡——傀儡随行（每 12 秒自动放出一具傀儡）、分神御物、驭兽（灵兽袋 +1）、神识如潮、一心多用（法宝三成几率连发）……直到大衍圆满。本命法宝是大衍傀儡：`V`「傀儡齐出」，四具傀儡同时现身，所有法宝立刻再出手一次。功法书里有，各层效果和本命法宝是为游戏拟的。
  - 毒系另有两门神通（毒瘴、蚀骨针）和五件物件（七毒水、五毒珠、腐骨毒砂、尸虫丸、缠香丝），不修毒经也能用。
- **青竹蜂云剑**（本命法宝）：结丹之后以天雷竹炼成。飞剑的外形随进境变三次（凡铁飞剑、青元剑光、青竹蜂云剑），到这一步是竹节剑身、金色雷弧，命中有几率引动辟邪神雷；飞剑命中会积攒**剑意**，满 100 后按 `V` 施展「蜂云剑阵」，七十二口飞剑倾巢而出、自行追击。
- **大庚剑阵**：炼成青竹蜂云剑之后，阵图会出现在首领遗物里（之后的机缘里也有机会）。得到后，`V` 改为在目标处布阵七秒：七十二口飞剑剑尖朝下环立成阵，入阵的敌人出不去，剑丝往复绞杀，不时落下辟邪神雷，收阵时再降一轮神雷。
- **修为感悟**：升层时三选一的属性强化（寻常 / 精妙 / 顿悟三档）。
- **神通**（14 门，至多同修三门，可升至三重）：火弹术、冰锥术、青元剑阵、辟邪神雷、巨剑术、噬金虫群、玄铁盾、傀儡术、风雷翅、颠倒五行阵、土牢术、血影遁、血灵钻、惊蛰十二变。三门修满后再得新神通，要舍弃一门来换。
- **功法**（15 种被动）：长春功、眨眼剑法、罗烟步、大衍诀、明王诀、梵圣真魔功、百脉炼宝诀、玄阴经、血灵大法、元磁神光……
- **法宝**（27 件）：一半是被动（金雷竹、乾蓝冰焰、混元钵、皇鳞甲、虚天鼎、紫罗极火、掌天瓶……），另一半会**自动祭出**——金光砖、乌龙夺、青蛟旗、天雷子、三焰扇、八灵尺、鬼罗幡、血魔剑、元磁神山、雪晶珠、黑风旗、玄天斩灵剑，各按自己的间隔自行出手，不占神通栏，不耗法力。
- **灵宠灵虫**（9 种，灵兽袋至多带三只）：噬金虫、血玉蜘蛛、六翼霜蚣、啼魂兽、银月、土甲龙、豹麟兽、曲魂、人形傀儡。常驻身侧，自行作战。
- **技艺**（6 门，各可修至三重）：炼丹术、炼器术、阵法、傀儡术、制符术、驱虫术。
- **丹药**：定灵丹、补天丹、九曲灵参、养魂木、回阳水、万年灵乳……
- **轮回感悟**：陨落后获得道心，可在「洞府」永久强化根基（存于浏览器本地）。

## 美术哲学

**凡尘为底，灵光点睛。** 凡尘低饱和、不发光，饱和度与亮度只发给灵力；看颜色知道是哪一路功法，看芯知道是谁放的（我方白芯带拖尾，敌方暗芯厚边），危险区域的预警只用朱砂；玩家的底子永远是布衣，流派只改变他身边的器物和光；每间房是云海里的一方盆景；四章由暖入寒。

参照有三：《定海》（青铜纹饰地台、苔石松灯的盆景浮岛、低饱和环境配高饱和特效）、《神舞幻想》（冷夜暖灯、祭台星图、素衣银饰）、《暖雪》（黑暗里的一圈光、墨线勾边、战斗在地上留痕、冷石暖烛）——只借原则，不借素材。

完整的法则、造型规范、色板，以及当前版本与它的差距，见 [`docs/art-philosophy.md`](docs/art-philosophy.md)。新增任何模型、特效、界面之前先看它。

## 渲染是怎么做的

游戏逻辑仍然跑在一张二维平面上（坐标单位是像素，48 像素一格），渲染层把它搬进三维：逻辑坐标 `(x, y)` 加离地高度 `z` → 三维坐标 `(x/48, z/48, y/48)`，一格等于一个单位。

- **相机**：透视相机，俯角约 48°、视场角 26°（窄视场让透视变形更小，接近经典的 2.5D 观感），跟随主角并按房间边界收束；鼠标位置通过射线与地面求交换算成瞄准点。
- **场景**：地面是一张按房间烘焙的 Canvas 贴图（不规则石板、青铜地台、落英苔痕）；墙按章节各有围法（庭院是粉墙黛瓦加石栏杆，密林是一圈山岩，围城是城墙垛口，古殿是玉墙玉柱），屋内的隔墙是假山、残垣或冰岩；北高、侧中、南矮，保证不挡视线。每间房坐落在一座削面石山上：岛缘、北面的山脊、云海里的石柱都由同一套山石几何体堆成，颜色烘在顶点上，最后合并成一个网格；北门是青铜环门，北墙上挂立轴。
- **人形角色**：KayKit 的 GLB 模型，用 `GLTFLoader` 解析、`SkeletonUtils` 克隆。六个基础角色通过贴图换色（在画布上逐像素改色相）和配件显隐，变出十五种角色。动画拆成上半身、下半身两层分别混合，所以可以边跑边出招；出招动画的进度直接由战斗逻辑里的蓄力 / 出手时刻驱动，动作和判定对得上。
- **其余模型**：妖兽、鬼物、墨蛟、场景物件由球、圆柱、圆锥、长方体等基础几何体拼装，带扑翼、蠕动、开合等程序化动画。静态物件在建房时合并成单个带顶点色的网格，减少绘制调用。
- **光影与层次**：半球环境光 + 一盏带阴影贴图的平行光（月光）+ 灯笼 / 火盆的点光源 + 跟随主角的补光。画面分五层：压暗成剪影的前景山石与树、最亮的场内、墙根的草丛、被雾推淡的北墙与山脊、发亮的云海与石柱；地面上有烘焙的灯光池、接地影和缓缓移动的云影，场内斜插几道很淡的光柱。
- **弹幕与特效**：敌方弹幕用 `InstancedMesh` 实例化绘制；粒子与光晕是一个自定义着色器的点云（加色混合）；地面预警圈、火墙、光束是贴地的半透明网格。
- **叠加层**：伤害飘字、血条、闪电与刀光画在一张 2D 画布上，位置由相机投影换算。

## 用 Tripo 模型替换角色

人形角色可以逐个换成 Tripo 生成的模型，流程：

1. 在 [Tripo Studio](https://studio.tripo3d.ai/) 生成角色（提示词见 [`tools/tripo-prompts.md`](tools/tripo-prompts.md)，风格与玩家形象统一），**绑骨时选 Mixamo 骨骼规范**，导出 FBX 或 GLB。不需要带动画。
2. 运行导入工具，名字用角色的键名：

   ```bash
   npm i @gltf-transform/core @gltf-transform/functions @gltf-transform/extensions sharp fbx2gltf
   node tools/import-tripo.mjs modaifu ~/Downloads/tripo_convert_xxx.fbx
   ```

   它会把 FBX 转成 GLB、把 8K 贴图缩到 1K、压缩网格，输出 `assets/tripo/modaifu.glb`，并重新打包 `assets/tripo.js`。
3. 刷新游戏。只要 `assets/tripo/` 里有与角色键名同名的模型，游戏就会自动用它，否则退回 KayKit 模型。

Tripo 导出的模型只有骨骼、没有动画。`js/assets.js` 里有一套针对 Mixamo 骨骼的程序化动作（待机、奔跑、御剑 / 施法、劈砍、举臂、闪避），所有 Tripo 人形角色共用。

```
js/game.js        主循环、单局流程、房间推进、奖励与局外成长
```

想调数值的话，绝大多数内容都在 `js/data.js`（名目与文案）和 `js/arsenal.js`（法宝、灵宠的伤害与间隔）；改完数据后运行 `node tools/make-codex.mjs` 重新生成图鉴；杂兵随章节的血量 / 伤害倍率在 `js/enemies.js` 顶部的 `HPM` / `DMGM`；相机俯角、视场角与距离在 `js/render.js` 顶部。

改完数值想看平衡，可以用试玩机器人（开发工具，不是游戏的一部分；需要 Node 和 Playwright）：

```
python3 -m http.server 8765 &
MAIN=du node tools/playtest-bot.js 5 40 0    # 用墨氏毒经打 5 局；MAIN 可取 qy / du / dy
```

加上 `PREFER=main` 可以让它升层时优先参悟主修功法。它不开无敌、只跑逻辑不渲染，一局一分多钟，每局末尾打印一行汇总（通关与否、用时、受伤、主修层数……）。机器人的打法很朴素，通关率只能横向比较（改动前后、三门功法之间），不能当成真人的难度。
