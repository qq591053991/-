# 凡人问道

一款以小说《凡人修仙传》为故事背景的 **2.5D 俯视角动作 Roguelike**。

纯原生 JavaScript + Canvas 2D，**零依赖、零构建、零素材文件**——所有角色、怪物、场景、特效均为程序化绘制，音效与配乐由 WebAudio 实时合成。

> 非商业同人作品。故事背景取材自忘语所著小说《凡人修仙传》，相关权利归原作者及权利方所有；游戏内文案均为同人原创改写。

## 运行

直接用浏览器打开 `index.html` 即可（无需服务器）。

也可以起一个静态服务：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

推荐使用桌面版 Chrome / Edge / Firefox / Safari；手机横屏亦可游玩（自带虚拟摇杆与自动瞄准）。

## 玩法

你将扮演资质平平的韩立，一局之内走完从凡俗到元婴的四段经历：

| 章节 | 场景 | 首领 | 破关之后 |
| --- | --- | --- | --- |
| 第一章 · 七玄门 | 神手谷（月夜庭院） | 墨大夫 | 长春功大成 |
| 第二章 · 血色禁地 | 赤雾密林 | 墨蛟 | 服筑基丹，突破筑基 |
| 第三章 · 魔焰滔天 | 燕翎堡（魔道围城） | 王蝉 | 远遁乱星海，凝结金丹 |
| 第四章 · 虚天残图 | 虚天殿（冰火古殿） | 极阴祖师 | 丹破婴生 |

每一章是一张随机生成的房间图：

- **险地 / 精英**：清空数波敌人后禁制解除。精英房额外掉落宝匣。
- **机缘**：法宝或神通三选一。
- **坊市**：用灵石购买丹药、法宝、神通。
- **药园**：每清空一间房，掌天瓶会凝出一滴**绿液**；在药园用绿液催熟灵药，换取永久强化。
- **奇遇**：带抉择的文字事件。
- **首领**：每位首领有两个阶段与多套招式。

成长来源：

- **修为感悟**：升层时三选一的属性强化（寻常 / 精妙 / 顿悟三档）。
- **神通**（至多三门，可升至三重）：火弹术、冰锥术、青元剑阵、辟邪神雷、巨剑术、噬金虫群、玄铁盾、傀儡术、风雷翅。
- **法宝 / 功法**（二十余种被动）：青元剑诀、金雷竹、噬金虫卵、乾蓝冰焰、青竹蜂云剑、大衍诀、万年灵乳……
- **轮回感悟**：陨落后获得道心，可在「洞府」永久强化根基（存于浏览器本地）。

## 2.5D 是怎么做的

没有用 3D 引擎，整套「伪三维」在 Canvas 2D 里完成：

- **倾斜俯视投影**：世界是平面坐标 `(x, y)` 加高度 `z`，绘制时 `屏幕y = y × 0.75 − z`，地面上的圆因此变成椭圆，飞剑、抛射物、飞行怪都有真实的离地高度和落在地上的影子。
- **墙体挤出与纵深排序**：墙按行烘焙成带顶面与立面的条带，与角色、物件、弹幕一起按 `y` 排序绘制，人物可以走到柱子、树、墙后面被遮挡。
- **动态光照**：每帧在离屏画布上铺一层环境暗色，再用径向光斑「挖」出灯笼、法术、角色周围的亮区，最后叠加一层辉光。
- **悬空平台**：每间房都是云雾中的一块浮台，南侧画出下坠的崖壁。

## 目录结构

```
index.html        入口
css/style.css     界面样式
js/core.js        命名空间、工具函数、键鼠与触屏输入
js/audio.js       WebAudio 合成的音效与五声音阶配乐
js/data.js        剧情文案、章节、敌人、神通、法宝、感悟、灵药、奇遇
js/art.js         程序化美术：角色、怪物、物件、地面与墙体烘焙
js/world.js       楼层房间图生成、单间地形、碰撞、寻路流场
js/entities.js    特效、伤害结算、玩家、飞行道具、地面招式、神通
js/enemies.js     敌人波次、十一类 AI、四位首领的招式脚本
js/render.js      投影、纵深排序、光照、粒子、小地图、主菜单背景
js/ui.js          菜单、HUD、三选一、坊市、药园、奇遇、对白、结算
js/game.js        主循环、单局流程、房间推进、奖励与局外成长
```

想调数值的话，绝大多数内容都在 `js/data.js`；杂兵随章节的血量 / 伤害倍率在 `js/enemies.js` 顶部的 `HPM` / `DMGM`。
