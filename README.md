# 凡人修仙传 · 斗法录（Roguelike）

《凡人修仙传》同人小游戏，**2.5D 俯视角**，玩法参考“俯视角射击 + 闪避”（类枪火地牢）与“波次竞技场 + 坊市构筑”（类 Brotato）两类 Roguelike。
纯网页运行（Three.js），**不依赖任何美术素材**：全部角色都是代码生成的低多边形 3D 模型（带走路、挥臂、僵尸跳、蛇身摆动等程序化动画），场景是低多边形松林、血晶、礁石与远山，贴图和音效也由代码现场生成。也可以把美术或 AI 生成的 GLB 模型放进 `public/models/` 直接替换（见下文）。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开终端里显示的地址
npm run build      # 类型检查 + 打包到 dist/（可直接部署到任意静态托管）
npm test           # 逻辑单元测试
```

## 玩法循环

1. **选起始法宝**：金蚨子母刃 / 火弹符 / 风刃符。
2. **斗法（波次）**：在限定时间内存活，敌人掉落灵石（同时是修为）。主修剑芒靠手动瞄准，法宝自动攻击。
3. **修为精进**：每升一层境界，波次结束后从 4 门功法里选 1 门（按凡品、灵品、玄品、天品分稀有度）。炼气十三层之后突破筑基、结丹……大境界突破有额外加成。
4. **坊市**：花灵石买法宝或丹药宝物，可以刷新货架。买到已持有的法宝会让它升一阶（下品→中品→上品→极品）。
5. **掌天瓶**：每过一波凝出 1 滴灵液，可以：
   - 催熟法宝：直接提升品阶；
   - 催熟灵药出售：换成灵石。
6. 共 **15 波、三张地图**，第 5、10、15 波是首领战，首领血量降到一半后会狂暴换招：

| 地图 | 波次 | 敌人 | 首领 |
|---|---|---|---|
| 七玄门 | 1–5 | 野狼帮众、箭手、妖狼、铁甲尸 | 墨大夫（半血后夺舍） |
| 血色禁地 | 6–10 | 血纹蛛、赤鳞兽、魔道修士 | 鬼灵门少主·王蝉（血灵钻冲锋） |
| 乱星海 | 11–15 | 阴魂、乱星海散修、海中妖蛟 | 极阴老祖（螺旋与环形弹幕） |

## 2.5D 与多机位首领演出

战斗逻辑仍在二维平面上运行（判定简单、稳定），渲染层把它映射到三维：地面 = XZ 平面，角色是 3D 模型，带接地影子，朝向平滑转向（玩家朝鼠标、近战敌人朝移动方向、远程敌人和首领朝玩家）；鼠标瞄准通过射线与地面求交得到。

每位首领有三段演出，由 `Director`（`src/game/camera.ts`）按镜头脚本（`src/game/cinematics.ts`）执行硬切、平滑过渡、荷兰角倾斜、慢动作和闪白：

| 首领 | 开场亮相 | 半血狂暴 | 伏诛 |
|---|---|---|---|
| 墨大夫 | 反打远景 → 正面低机位推近 | 「夺舍」侧面特写 + 荷兰角倾斜 | 慢动作环绕 |
| 王蝉 | 反打远景 → 侧面低机位横移 | 「血灵钻」低机位侧拍 → 甩镜到另一侧 | 慢动作环绕 |
| 极阴老祖 | 反打远景 → 仰拍环绕 | 「玄阴魔功」从近处升到正上方并旋转 180° | 慢动作环绕 |

演出期间战斗暂停（伏诛时为 0.2 倍慢动作），屏幕出现电影黑边、竖排书法题名和台词。新增演出只需在 `cinematics.ts` 里写镜头数组，每个镜头定义：时长、过渡时长、游戏流速、`pose(焦点, 进度) → {位置, 偏航, 俯仰, 距离, 视角, 倾斜}`。

### 替换为自定义 GLB

在 `public/models/manifest.json` 登记即可替换对应角色，未登记的继续使用内置模型（字段说明见 `public/models/README.md`）：

```json
{ "models": { "player": "hanli.glb", "modaifu": { "file": "mo.glb", "yaw": 90 } } }
```

模型会自动缩放到该角色的标准高度并贴地；若带动画，会按名称自动选用 walk/run、idle、attack/cast。适合接入 Tripo、Meshy、混元 3D 等 AI 3D 生成工具导出的模型。

## 目录结构

```
src/
  core/      输入、数学工具、合成音效
  data/      纯数据：法宝、宝物、功法、敌人、波次、境界、稀有度（改数值只需改这里）
  game/      游戏循环与战斗（game.ts）、敌人与首领 AI、法宝系统、坊市逻辑、
             摄像机与演出导演（camera.ts）、首领镜头脚本（cinematics.ts）
  render3d/  Three.js 场景（scene.ts）、程序化 3D 模型与动画（models.ts）、GLB 替换加载（glb.ts）、
             程序化贴图（textures.ts）、2D 界面层（hud.ts）
public/models/  可选的自定义 GLB 模型与清单
  ui/        DOM 界面：标题、选法宝、升级、坊市、暂停、结算
tests/       vitest 单元测试（境界、数据完整性、坊市规则、摄像机与演出、模型）
```

## 后续可以扩展的方向

- **美术**：用 AI 3D 生成工具或美术制作 GLB 模型，放进 `public/models/` 替换内置模型；可加描边 / 水墨着色器强化国风。
- **更多演出**：首领的特定招式（如王蝉冲锋）也可以触发短镜头。
- **多角色**：南宫婉、厉飞雨等，各自起始法宝和被动不同（参考 Brotato 的角色体系）。
- **房间制地图**：把竞技场换成枪火地牢式的随机房间与宝箱房。
- **局外成长**：解锁新法宝、宝物和难度（“道心”等级）。
- **数值平衡**：目前中后期偏容易，建议加大 11–15 波的刷怪密度和精英怪比例。
