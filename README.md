# 凡人修仙传 · 斗法录（Roguelike）

《凡人修仙传》同人小游戏，玩法参考“俯视角射击 + 闪避”（类枪火地牢）与“波次竞技场 + 坊市构筑”（类 Brotato）两类 Roguelike。
纯网页运行，**不依赖任何美术素材**：角色、敌人用水墨圆团配书法字形表示，音效用 WebAudio 实时合成。

> 同人作品，仅供学习交流，**非商业用途**。原著版权归作者忘语及相关权利方所有。若要公开发行或商用，需要另行取得授权，或把设定替换为原创内容。

## 运行

```bash
npm install
npm run dev        # 本地开发，浏览器打开终端里显示的地址
npm run build      # 类型检查 + 打包到 dist/（可直接部署到任意静态托管）
npm test           # 逻辑单元测试
```

## 玩法循环

1. **选起始法宝**：金蚨子母刃 / 火弹符 / 风刃符。
2. **斗法（波次）**：在限定时间内存活，敌人掉落灵石（同时是修为）。主修剑芒靠手动瞄准，法宝自动攻击。
3. **修为精进**：每升一层境界，波次结束后从 4 门功法里选 1 门（按凡品、灵品、玄品、天品分稀有度）。炼气十三层之后突破筑基、结丹……大境界突破有额外加成。
4. **坊市**：花灵石买法宝或丹药宝物，可以刷新货架。买到已持有的法宝会让它升一阶（下品→中品→上品→极品）。
5. **掌天瓶**：每过一波凝出 1 滴灵液，可以：
   - 催熟法宝：直接提升品阶；
   - 催熟灵药出售：换成灵石。
6. 共 **15 波、三张地图**，第 5、10、15 波是首领战，首领血量降到一半后会狂暴换招：

| 地图 | 波次 | 敌人 | 首领 |
|---|---|---|---|
| 七玄门 | 1–5 | 野狼帮众、箭手、妖狼、铁甲尸 | 墨大夫（半血后夺舍） |
| 血色禁地 | 6–10 | 血纹蛛、赤鳞兽、魔道修士 | 鬼灵门少主·王蝉（血灵钻冲锋） |
| 乱星海 | 11–15 | 阴魂、乱星海散修、海中妖蛟 | 极阴老祖（螺旋与环形弹幕） |

## 目录结构

```
src/
  core/      输入、数学工具、合成音效
  data/      纯数据：法宝、宝物、功法、敌人、波次、境界、稀有度（改数值只需改这里）
  game/      游戏循环与战斗（game.ts）、敌人与首领 AI、法宝系统、坊市逻辑、Canvas 渲染
  ui/        DOM 界面：标题、选法宝、升级、坊市、暂停、结算
tests/       vitest 单元测试（境界、数据完整性、坊市规则）
```

## 后续可以扩展的方向

- **美术**：用 AI 生图做统一画风的水墨角色立绘和敌人贴图，替换 `render.ts` 里的圆团绘制。
- **多角色**：南宫婉、厉飞雨等，各自起始法宝和被动不同（参考 Brotato 的角色体系）。
- **房间制地图**：把竞技场换成枪火地牢式的随机房间与宝箱房。
- **局外成长**：解锁新法宝、宝物和难度（“道心”等级）。
- **数值平衡**：目前中后期偏容易，建议加大 11–15 波的刷怪密度和精英怪比例。
