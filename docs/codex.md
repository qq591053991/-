# 图鉴

> 本文件由 `tools/make-codex.mjs` 从 `js/data.js` 生成，请勿手改。

游戏里所有能拿到的东西。名目取自《凡人修仙传》，效果是为这款游戏重新设计的。

- **功法**：被动，改变你的根基。
- **神通**：主动施放，至多同修三门（`Q` `E` `R`），每门可升至三重。栏满后再得新神通，需舍弃一门。
- **法宝**：一部分是被动；标着「自动祭出」的会按各自的间隔自行出手，不占神通栏，不耗法力。
- **灵宠**：常驻身侧、自行作战，不会受伤。灵兽袋至多带三只（驱虫术二重后四只）。
- **技艺**：炼丹、炼器、阵法、傀儡、制符、驱虫，各可修至三重。
- **丹药**：一次性的永久增益。

## 尚未收录

原著里的东西远不止这些。下面这些是已经想到、但这一版还没有做进来的，按大类列出：

- **人界篇**：神风舟等飞行法器、无形针与各类符宝、天都尸火、五子同心魔、冰魄寒光、鬼灵门与合欢宗的各式魔器、古修士的阵旗阵盘（除颠倒五行阵外）、通天灵宝的其余仿制品、虚天殿与昆吾山的其余宝物。
- **灵界篇**：涅槃圣体与真灵血脉的其余变化、玄天如意刃等玄天之宝、噬金虫王与成熟体、啼魂兽的进阶形态、广寒界与魔界所得的诸般宝物、各族的天赋神通。
- **仙界篇**：全部未收录。
- **功法**：除青元剑诀外，其余功法目前只是被动，还没有各自的主修线（普通攻击形态、进境三态、尽出一招）。
- **技艺**：目前是被动加成，没有做成需要材料与配方的炼制玩法。

合计：神通 14 门，功法 / 法宝 / 灵宠 / 技艺 / 丹药 共 64 种，灵药 7 种。
